# 学习过程记录

每次完成一个主题或遇到值得复盘的问题，就复制下面的模板，新建一篇记录。建议文件名：`YYYY-MM-DD-主题.md`。

公共仓库中的记录只保留通用步骤和脱敏结果。真实主机、内部域名、代理地址、凭据和业务名称应放在未提交的本地记录中。
