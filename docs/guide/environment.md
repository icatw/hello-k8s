# 环境与安全边界

## 推荐练习环境

优先使用专用本地虚拟机、云主机或实验集群。单节点学习环境通常可以从以下规格开始：

- 2–4 vCPU
- 4–8 GiB 内存
- 40 GiB 以上可用磁盘
- 能访问镜像仓库或配置受控的镜像代理
- 当前用户可以管理 Kubernetes 和本机服务

如果与其他应用共用主机，必须额外检查 CPU、内存、磁盘 I/O、端口、路由、容器运行时和数据备份。测试环境也要保留回滚和恢复路径。

## 开始前检查

- [ ] 当前主机用途、操作系统和版本已记录
- [ ] CPU、内存、磁盘空间和 swap 已检查
- [ ] 现有容器、服务和监听端口已盘点
- [ ] Pod、Service 网段与主机和企业网络没有冲突
- [ ] 需要使用的端口已检查，特别是 80、443、6443、10250
- [ ] 镜像仓库访问方式已确认；需要代理时已明确代理范围
- [ ] 重要数据有独立备份，练习数据可以丢弃

## 安全边界

- 公共教程使用占位符，例如 `<练习主机>`、`<代理地址>` 和 `<镜像仓库>`。
- 不提交 kubeconfig、证书、访问令牌、密码、私钥或含凭据的完整配置。
- 不把真实主机 IP、内部域名、业务容器名和公司专有信息写入公共记录。
- 练习清理前确认 namespace 和资源名称，避免使用范围不清楚的全局删除命令。
- 每次环境变化后更新记录，不把一次实验的现象当成通用结论。
